# Image-derived gradient correspondence — bounded diagnostic

Scope Core/Interpolation tooling only. Installed NumPy/Pillow are used for offline bounded-pair analysis, not introduced as runtime dependencies or a replacement for Swift/Metal MCFI. The probe detects minimum-eigenvalue corners, creates rotation-normalized4×4-cell/8-orientation gradient descriptors at three supports, applies distinct-feature distance ratio and mutual matching, and fits up to three deterministic affine models with at least six inliers. This is an original small diagnostic, not a complete SIFT implementation or an established production estimator.

`python3 Core/Interpolation/Tools/feature_correspondence_probe.py --selfcheck` passes blank input plus known0.25rad rotation/(-48,-12) translation:175 matches, median correspondence error0.76009px,175 model inliers. The fit is checked independently at three known control points, error<2px. Explicit descriptor dot-product reduction avoids platform BLAS floating-status warnings; finite values are asserted. No video file is copied, converted or modified.

For the stored Avatar300s pair:280/112 detected points,21 ratio/mutual matches, one supported model with6 inliers. Its transform is near identity (background), not the missing facial motion. Moving-face-looking matches are sparse and inconsistent across changed pose; they do not form a separately supported affine model under the same gate. No gate was relaxed to manufacture a foreground result. Descriptor construction/matching/model fitting costs approximately1s in this offline Python reference; this is not a real-time result or a prediction of native implementation cost.

The small permanent result is `assets/patch-stage-2026-10-16/feature-correspondences.json`. Example image run: `python3 Core/Interpolation/Tools/feature_correspondence_probe.py docs/diagnostics/assets/patch-stage-2026-10-16/input0.png docs/diagnostics/assets/patch-stage-2026-10-16/input1.png --out /tmp/rift-feature-avatar300.json`.
